# local2md

문서를 **서버로 전송하지 않고** 브라우저 안에서 Markdown으로 변환하는 웹 앱입니다.
파일을 선택하면 로컬에서 변환한 뒤 `.md` 파일로 내려받을 수 있습니다.

Files in. Markdown out. Nothing uploaded.

## 주요 특징

- **완전한 로컬 처리** — 파일과 변환 결과를 서버로 보내거나 자동 저장하지 않습니다. 모든 처리는 브라우저 안에서 이루어집니다.
- **다양한 형식 지원** — 문서, 데이터, 프레젠테이션, 압축, 이미지 등 일상적인 파일을 하나의 Markdown으로 변환합니다.
- **미리보기 및 다운로드** — 변환 결과를 화면에서 확인하고 `.md` 파일로 내려받을 수 있습니다. 긴 결과는 앞부분만 미리 보여주고, 다운로드에는 전체 내용이 포함됩니다.
- **다국어 지원** — 브라우저 언어를 감지해 한국어, 영어, 일본어, 중국어(간체/번체)를 자동으로 적용합니다.
- **접근성** — 스크린리더용 라이브 영역, 키보드 조작, 건너뛰기 링크를 지원합니다.

## 지원 형식

### 브라우저에서 바로 변환

| 분류 | 확장자 |
| --- | --- |
| 문서 | `PDF`, `DOCX`, `HWP`, `HWPX`, `HTML`, `EPUB` |
| 데이터 | `XLSX`, `CSV`, `XLS`, `JSON`, `XML`, `TSV` |
| 프레젠테이션·피드 | `PPTX`, `RSS`, `Atom`, `IPYNB` |
| 압축 | `ZIP` |
| 이미지 | `JPEG`, `PNG` (기본 메타데이터만 변환) |

### 추가 provider 필요

아래 기능은 별도의 변환 서비스가 필요하며, 현재 버전에서는 지원하지 않습니다.
외부 서비스를 연결하지 않으며 변환을 위한 외부 요청을 자동으로 만들지 않습니다.

- 스캔 PDF, `MSG`, 오디오, 이미지 OCR, 이미지 내용 설명

## 사용 방법

1. 파일을 선택하거나 화면의 드롭 영역에 끌어다 놓습니다.
2. 브라우저에서 변환합니다.
3. 결과를 미리 확인한 뒤 Markdown을 다운로드합니다.

한 번에 파일 하나씩, 최대 **20MB**까지 선택할 수 있습니다. 새로고침하거나 탭을 닫으면 결과가 사라지므로 필요한 Markdown은 미리 내려받으세요.

## 기술 스택

- 순수 HTML/CSS/JavaScript (빌드 도구 없음)
- [MarkItDown](https://github.com/microsoft/markitdown) 기반 변환기 (`markitdown.js`, WebAssembly)

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 앱 마크업 및 SVG 아이콘 정의 |
| `app.js` | 변환 흐름, 드래그 앤 드롭, UI 상태 관리 |
| `converter-utils.js` | 파일 검증, 크기·이름 포맷, 오류 분류 |
| `i18n.js` | 로케일 로딩 및 번역 적용 |
| `markitdown.js` | MarkItDown 변환 라이브러리 |
| `styles.css` | 스타일시트 |
| `locales/` | 언어별 번역 (`en`, `ja`, `ko`, `zh-Hans`, `zh-Hant`) |
| `assets/` | 정적 자원 |
| `local2md_180.png` | 파비콘·앱 아이콘 |

## 배포

이 디렉터리는 정적 호스팅 결과물입니다. 별도 서버나 백엔드 없이 정적 파일만 호스팅하면 됩니다.

- GitHub Pages: 저장소 설정에서 브랜치를 배포 소스로 지정
- 기타 정적 호스팅(Netlify, Cloudflare Pages, S3 등): 디렉터리를 그대로 업로드
